# 🌿 REWORLD — Bağış Platformu

## Proje Adı
**REWORLD** — Eşyalar için ikinci şans, toplum için ilk adım.

## Problem
Her gün binlerce kitap, kıyafet ve gıda ürünü, ihtiyacı olan birine ulaşamadan çöpe atılıyor. İnsanların bağış yapmak istediği ama nereye, nasıl yapacağını bilmediği bir boşluk var. Öte yandan ihtiyaç sahipleri de bu eşyalara nasıl ulaşacaklarını bilmiyor. REWORLD, bu iki tarafı buluşturan köprüdür.

## Nasıl Çalışır?
1. Bağışçı, platformda ücretsiz olarak eşyasını listeler (kitap, kıyafet veya gıda).
2. İhtiyaç sahibi listedeki eşyayı görüp talep eder.
3. Eşya, **sadece kargo ücreti** karşılığında (bağışçı veya alıcı tarafından) gönderilir.
4. Hiçbir ticari ücret, komisyon veya kazanç yoktur. Platform tamamen gönüllülük esasına dayanır.
5. AI destekli öneri sistemi, kullanıcıya en uygun eşyaları ve bağışları önerir.

## Kurulum & Çalıştırma

```bash
# Depoyu klonla
git clone https://github.com/kullanici/yenidehayat.git
cd REWORLD

# Bağımlılıkları yükle
pip install -r requirements.txt

# Uygulamayı başlat
python app.py
```

Tarayıcıda `http://localhost:5000` adresini aç.
